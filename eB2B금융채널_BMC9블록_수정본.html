신용보증기금 MP사 연계 eB2B 금융·경영지원 아웃소싱 채널 — 비즈니스 모델 캔버스

Business Model Canvas · 9 Block · 담당자: 정승철
비용 영역 · 실현 가능성 (Feasibility)
매출 영역 · 수용 가능성 (Desirability)
수익 영역 · 생존 가능성 (Viability)

8핵심 파트너십

  • 신용보증기금 협약 MP사(eB2B 마켓플레이스 운영기업)
  • 신용보증기금·기술보증기금(보증서 발급 심사)
  • 협업 시중은행(B2B 대출 연계)

7핵심 활동

  • 탭·배너 기획, 원스톱 API 연동시스템 개발
  • 'B2B 사무 팩' 표준화, 서류대행 패키지 출시
  • 우수회원사 금융상품 추천→재이용 유도
  • 금융심사서류 사전검토·검수
  • 파트너 교육과정 수료·테스트 검증

6핵심 자원

  • B2B 금융서류 준비 전문 파트너(이루미)
  • 금융구조 교육 이수한 이루미 정예풀
  • 원스톱 API 연동 시스템·인프라

2가치 제안

  • 계약서·정산·세무증빙을 플랫폼 내 즉시 해결하는 경영지원 아웃소싱
  • 대출한도 승인 지연 해결 + MP사 금융중개 성공률 향상
  • MP수수료 면제·신보 가점추천 등 원스톱 자금조달 프로세스
  • B2B 금융 메커니즘 전문교육 이수 파트너(이루미) 투입
  • 개별매칭 아닌 표준화된 'B2B 사무 팩' 패키지 제공

4고객 관계

  • 매칭~정산 심리스 연동으로 신뢰관계 유지
  • 검증된 파트너의 일관된 대행품질 보장
  • 건당결제→구독전환 유도로 고정고객화
  • 패키지 가입 유도로 구독 락인 극대화

3채널

  • eB2B 플랫폼 내 전용 탭·배너 밀착 노출
  • 기존 회원사 네트워크 활용, CAC 70%+ 절감
  • API 기반 신청~정산 원스톱 처리

1고객 세그먼트

  • 신보 협약 MP사 eB2B 회원사(구매·판매기업)
  • 인력부족·행정업무 과중 겪는 회원사
  • 보증서·B2B대출 서류준비 어려움 겪는 회원사
  • 제조·유통·도소매형(정산·매출채권 반복업무)
  • 자금조달형(보증서·대출 신속서류 필요)

9비용 구조

  • 인건비: 이루미 수행비 + PM 인건비(고정)
  • 플랫폼비: 배너·탭 구축, API 연동 개발·인프라 유지
  • 마케팅비: eB2B 직통채널 내 프로모션(변동)
  • 변동비: 이루미 정산비 + MP사 추천수수료 5~10%

5수익원

  • 결제액 기준 5~10% B2B 추천수수료(Referral Fee)
  • 월 정기 구독 요금제(SaaS)를 통한 반복수익
  • 월 10시간 바우처 결합 프리미엄 패키지
  • Basic·Standard·Premium 구독형 요금 구조(구독비중 40%+ 목표)
